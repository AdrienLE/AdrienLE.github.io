Gmail Filter Rules

Gmail Filter Rules is a personal Google Sheets and Apps Script tool maintained by Adrien Ecoffet. It turns enabled spreadsheet rules into Gmail filters that skip the inbox, while keeping the rule definitions and status visible in the spreadsheet.

Each rule identifies an exact sender and a subject condition or Gmail search query. The script checks the sheet on a recurring schedule. When requested for a rule, it also archives existing matching inbox messages and records the affected message identifiers in the sheet's archive log.

An authorized Codex workflow can add or update rules in the same spreadsheet when the user explicitly requests it. This script uses Gmail search criteria; it does not classify message content with an AI model.

This is a personal utility, not a public service. Read the privacy policy and terms of use before authorizing it.
