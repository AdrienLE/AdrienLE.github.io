Privacy — Gmail Filter Rules

Effective November 7, 2026

Access and purpose

Gmail Filter Rules uses Google authorization to read the Gmail account identity, list and manage Gmail filters, find matching inbox message identifiers, and remove the INBOX label from matching messages when an existing-mail backfill is requested. It reads rule definitions from its Google spreadsheet and writes filter identifiers, status, timestamps, and archive-log entries there.

The script requests Sheets access, Gmail filter settings access, Gmail modification access, and permission to manage its Apps Script triggers. Gmail modification is a broad Google permission; the current script does not send email, delete messages, or read message bodies. It searches message metadata through Gmail and archives by message identifier.

Storage and processing

The script runs on Google's Apps Script infrastructure. Rule definitions and archive logs are stored in the user's spreadsheet. The script stores its spreadsheet binding and managed-filter identifiers in Apps Script properties. Google may retain execution and error logs. Gmail stores the installed filters and message labels.

The script does not call an AI service or send mailbox data to an external server. If the user asks Codex to manage rules, that separate, authorized Codex workflow may read relevant email and spreadsheet information using its own connections. Its processing is subject to the user's OpenAI service settings. Spreadsheet collaborators can see the rules and logs according to the spreadsheet's sharing permissions.

Gmail Filter Rules does not sell Google user data or use it for advertising. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The script does not use Google user data to develop or train generalized AI models.

Stopping and removing data

Disable a rule and allow the script to confirm its disabled status to remove filters it owns for that rule. Separately managed Gmail filters are preserved. Stopping the trigger or revoking authorization prevents subsequent script runs but does not remove already installed Gmail filters; these can also be removed in Gmail settings.

You can stop the recurring Apps Script trigger and revoke the app through your Google Account connections. Rules and archive logs remain until you delete them from the spreadsheet; Apps Script properties remain until you remove them or the script project. Execution logs follow Google's retention controls. Contact the address below for help identifying or removing app-held data. Archiving keeps messages in Gmail and can be reversed by moving them to the inbox.
